# GitHub Actions Fundamentals Assignment

## Project
This is a simple React application created using Vite.

## CI/CD
CI/CD stands for Continuous Integration and Continuous Deployment. It automates the process of building and testing code whenever changes are pushed to the repository.

## Self-hosted Runner
A self-hosted runner is a machine managed by the developer that executes GitHub Actions workflows instead of GitHub-hosted servers.

## Workflow Execution Process
1. Code pushed to development branch
2. GitHub Actions detects push event
3. Workflow starts automatically
4. Self-hosted runner picks up the job
5. Project dependencies are installed
6. React application builds successfully
